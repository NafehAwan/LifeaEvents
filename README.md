# LifeaEvents

A GUI-based event/minigame management plugin for Paper 1.21.x.

Players host and join events from a single `/event` command; each event runs one
of six minigames with its own pre-lobby, scoreboard, music and arena setup wizard.

## Minigames

| Minigame | Goal |
| --- | --- |
| Mace Roulette | Survive spinning mace rounds; get knocked off the arena and you're out. |
| Team Fight | Red vs. Blue deathmatch, first team to the target score wins. |
| Hide and Seek | Hiders survive the timer; seekers tag them into their ranks. |
| Hot TNT | Pass the lit TNT before the fuse runs out. |
| Spleef | Break the snow beneath other players; last one standing wins. |
| Red Light, Green Light | Move on green, freeze on red, first to the finish line wins. |

## Commands & permissions

`/event <join|leave|spectate|music|host|setup|admin|reload|stop>` (alias `/events`).

- `lifeaevents.use` – join/leave/spectate (default: everyone)
- `lifeaevents.host` – host an event
- `lifeaevents.admin` – arena setup, reload, force-stop

## Building

Requires JDK 21 and Maven. The build depends on the Paper API from the PaperMC
repository (`https://repo.papermc.io/repository/maven-public/`).

```sh
mvn clean package
```

The shaded jar is written to `target/LifeaEvents.jar`.

## Configuration

- `config.yml` – pre-game countdown, per-minigame timings and player limits
- `messages.yml` – every player-facing message (MiniMessage formatting)
- `scoreboard.yml` – per-minigame sidebar layouts
- `arenas.yml` / `mace_arenas.yml` – generated by the in-game setup wizard

## Provenance

This repository was reconstructed from a compiled `LifeaEvents.jar` (the original
source was not available). Behaviour matches the shipped plugin except for the
bug fixes committed on top.
